**Panak**-ը ժամանակակից, սահուն եւ գերարագ աշխատող ծրագիր է Windows օպերացիոն համակարգի համար (C# / .NET 8 WPF), որը **Android OS-ի / Material You-ի պանակների (Folder Widgets)** հարմարավետությունն ու էսթետիկան տեղափոխում է Windows-ի աշխատասեղան:

Դասական, ծանրաշարժ պանակներ բացելու եւ աշխատասեղանը նիշքերով ծանրաբեռնելու փոխարեն՝ Panak-ը թույլ է տալիս ակնթարթորեն բացել ապակեպատ (frosted-glass) Popup պատուհաններ՝ դինամիկ պատկերակներով, արագ ստեղներով, սահուն անիմացիաներով եւ Windows Explorer-ի ամբողջական ինտեգրմամբ:

## Սահուն Scale & Morph անիմացիա

Panak-ը լիովին վերարտադրում է Android OS-ի հայտնի widget անիմացիաները.
- **Կոորդինատային խոշորացում**․ Պանակը բացվում է անմիջապես այն պատկերակի էկրանային դիրքից, որի վրա կտտացրել եք (Desktop-ում կամ Explorer-ում)՝ սահուն վերածվելով Popup քարտի:
- **Կենտրոնում բացման ընտրանք**․ Կայանքներից հնարավոր է միացնել, որպեսզի պանակները միշտ բացվեն էկրանի կենտրոնում:
- **Սահուն փակում**․ `Esc`, արտաքին ետնաշերտի վրա կտտոցը կամ որեւէ նիշք բացելը սահուն կերպով հետ է փոքրացնում պատուհանը՝ այն վերադարձնելով պատկերակի մեջ:

## Դինամիկ 2x2 նախադիտման պատկերակներ (Icon Engine)

Սովորական Windows պանակները միանման են եւ անհետաքրքիր: Panak-ը փոխում է դա.
- **2x2 Ցանցային նախադիտում**․ Գեներացնում է բարձրորակ պատկերակ, որտեղ արտացոլվում են պանակի ներսում գտնվող առաջին 4 նիշքերի մանրապատկերները (Android Grid ոճով):
- **Windows Cache շրջանցման մեխանիզմ**․ Windows Explorer-ը հայտնի է պատկերակները համառորեն քեշավորելու իր հատկությամբ: Panak-ն օգտագործում է հաջորդական սլոտերի ռոտացիա (`panak_icon_{N}.ico` `desktop.ini`-ի մեջ)՝ ստիպելով Windows Shell-ին վայրկենապես թարմացնել տեսքը նիշք ավելացնելիս կամ հեռացնելիս:
- **Բազմաչափ ICO նիշքեր**․ Պատկերակները գեներացվում են բոլոր չափերով (256×256, 48×48, 32×32, 16×16)՝ Explorer-ի ցանկացած մասշտաբում հստակ երեւալու համար:

## Ապակեպատ Acrylic / Frosted Glass միջերես

Ստեղծված է ժամանակակից Fluent եւ Material 3 դիզայնի կանոններով.
- **Իրական ժամանակի Gaussian Blur**․ Աշխատասեղանի պաստառը սահուն լղոզվում է բացված Popup քարտի ետեւում:
- **Թեմայի ընտրանքներ**․

  - **Auto (Համակարգային)**՝ Ինքնաշխատ համաժամեցվում է Windows-ի գործող թեմայի հետ:

## Ենթապանակներ (Subfolders) եւ Breadcrumbs նավարկում

Panak-ը սահմանափակված չէ միայն առաջին մակարդակի նիշքերով.
- **Ներքին պանակների բացում**․ Popup-ի մեջ ցանկացած ենթապանակի վրա կտտացնելիս այն բացվում է նույն պատուհանում:
- **Breadcrumbs հասցեագոտի**․ Հեշտությամբ տեսեք ձեր գտնվելու վայրը եւ կտտացրեք նախորդ պանակներին վերադառնալու համար:
- **Հետ վերադարձի կոճակ**․ Սեղմեք `←` կոճակը կամ `Backspace` ստեղնը:
- **Նիշքերի հաշվիչ**․ Վերնագրի կողքի կրծքանշանը ցույց է տալիս տարրերի ընդհանուր քանակը:

- **Ներս գցել**․ Քաշեք ցանկացած նիշք կամ պանակ Desktop-ից, Explorer-ից կամ բրաուզերից ու գցեք Panak-ի մեջ:
- **Դուրս քաշել**․ Popup-ից նիշքը քաշեք դեպի Desktop, մեկ այլ պանակ կամ այլ ծրագրեր:
- **Նիշքը նիշքի վրա գցելու միավորում (Android / iOS ոճով)**․
  - Desktop-ում մեկ նիշքը քաշեք եւ գցեք մեկ այլ նիշքի վրա:
  - Panak-ի Windows Shell Extension-ը (`Panak.ShellExt.dll`) կառաջարկի երկու նիշքերը միավորել նորաստեղծ Panak պանակում:

| **Կտտոց ետնաշերտին** | Էկրանի մթագնած ետնաշերտ | Սահուն փակում է բացված պանակը: |

## Windows Explorer-ի եւ Աջ կտտոցի (Context Menu) ինտեգրում

### Ընտրացանկի հրամանները Windows-ում
- **Աջ կտտոց նիշք(եր)ի վրա** ➔ `«Ստեղծել Android-ոճի պանակ»`․ Ընտրված նիշքերը հավաքում է նոր Panak պանակում:
- **Աջ կտտոց պանակի վրա** ➔ `«Բացել Panak-ով»`․ Բացում է պանակը Panak-ի Popup տեսքով:
- **Աջ կտտոց պանակի վրա** ➔ `«Վերածել Panak պանակի»`․ Սովորական պանակը դարձնում է Panak պանակ՝ գեներացնելով 2x2 պատկերակ:
- **Աջ կտտոց պանակի վրա** ➔ `«Վերածել սովորական պանակի»`․ Հեռացնում է Panak-ի կայանքները:
- **Աջ կտտոց դատարկ տարածքի վրա** ➔ `«Նոր Panak պանակ»`․ Ստեղծում է նոր դատարկ Panak պանակ:

### Գործողությունները Popup-ի ներսում
- **Բացել**․ Գործարկում է նիշքը համապատասխան ծրագրով կամ բացում է ենթապանակը:
- **Բացել Windows Explorer-ում**․ Ցույց է տալիս նիշքը Explorer-ի մեջ:
- **Հանել պանակից**․ Տեղափոխում է նիշքը պանակից դուրս:
- **Ջնջել**․ Հեռացնում է նիշքը:
- **Հատկություններ**․ Բացում է Windows-ի նիշքի հատկությունների պատուհանը (Properties):

## System Tray եւ Կայանքների վահանակ

Panak-ն աշխատում է Windows-ի ծանուցումների սկուտեղում (System Tray)՝ նվազագույն ռեսուրսների ծախսով:
- **Ձախ կտտոց tray պատկերակին**․ Բացում է Կայանքների վահանակը:
- **Աջ կտտոց tray մենյուին**․
  - **Կայանքներ**․ Համակարգային կայանքների պատուհան:
  - **Նոր Panak պանակ**․ Ստեղծում է նոր պանակ Desktop-ում:
  - **Աջակցել նախագծին**․ Ko-fi էջի հղում:
  - **Ստուգել թարմացումները**․ GitHub-ի ստուգում:
  - **Ելք**․ Ծրագրի փակում:

### Կայանքների բաժինները
1. **Ընդհանուր (General)**․ Լեզվի ընտրություն, Windows-ի հետ մեկնարկ (AutoStart), Ko-fi աջակցություն:
2. **Արտաքին (Appearance)**․ Սյուների քանակ (3–8), Թեմա (Լուսավոր/Մուգ/Auto), Նախադրված ձեւ եւ պաստելային գույն:
3. **Վարքագիծ (Behavior)**․ Focus Mode-ի եւ մթագնման աստիճանի կայանքներ, Բացել միայն կենտրոնում, Պանակների կողպում:
4. **Ինտեգրում (Integration)**․ Explorer Context Menu, Drag & Drop-ով նիշքերի միավորում, Աջ կրկնակտտոց, Space Quick Look:
5. **Թարմացումներ (Updates)**․ Տարբերակի ստուգում, փոփոխությունների ցանկ եւ ավտոմատ ներբեռնում:

## Տեղադրում եւ Ապատեղադրում

Panak-ի տեղադրման համար **Administrator իրավունքներ պետք չեն**:

### Տարբերակ 1. Մեկ կտտոցով տեղադրիչ (Խորհուրդ տրվող)
1. Ներբեռնեք `Panak-Installer-vX.X.X.zip` փաթեթը [Releases](https://github.com/hranthakobian/Panak/releases) բաժնից:
2. Բացեք արխիվը եւ գործարկեք **`Setup.exe`** (կամ `scripts\Install.bat`):
3. Հետեւեք քայլերին. ծրագիրը տեղադրվում է `%LocalAppData%\Programs\Panak` պանակում:

### Տարբերակ 2. Հրամանային տողով (CLI)
```powershell
# Գրաֆիկական տեղադրիչ
Panak.exe --install

# Անձայն / Ավտոմատ տեղադրում
Panak.exe --install-silent
```

### Ապատեղադրում (Uninstall)
Panak-ը կարելի է հեռացնել հետեւյալ եղանակներից որեւէ մեկով.
- Գործարկեք **`Uninstall.exe`** կամ **`Uninstall.bat`**, կամ
- Panak-ի **Կայանքներում** (Settings) սեղմեք **Ապատեղադրել** (Uninstall), կամ
- Բացեք **Windows Settings ➔ Apps ➔ Installed apps ➔ Panak ➔ Uninstall**:

Առանձին ապատեղադրիչը (`Uninstall.exe`) ցուցադրում է դինամիկ Material You լոգո, հետադարձ կապի հղումներ, .NET 8.0 Desktop Runtime-ը ջնջելու ընտրանք, եւ մաքրում է գրանցամատյանի բոլոր գրառումները, կոնտեքստային մենյուները, դյուրանցումները եւ ծրագրային նիշքերը:

## Հրամանային տողի միջերես (CLI)

Panak-ն ունի հզոր IPC ճարտարապետություն՝ աջակցելով հետեւյալ հրամաններին.

```bash
# Բացել տվյալ պանակը Panak Popup տեսքով
Panak.exe --open "C:\Path\To\Folder"

# Ստեղծել Panak պանակ՝ ներառելով նշված նիշքը
Panak.exe --create "C:\Path\To\File.txt"

# Վերածել սովորական պանակը Panak-ի (գեներացնելով 2x2 պատկերակ)
Panak.exe --convert "C:\Path\To\Folder"

# Ստեղծել նոր դատարկ Panak պանակ տվյալ վայրում
Panak.exe --new "C:\Path\To\TargetDirectory"

# Բացել Կայանքների պատուհանը
Panak.exe --settings

# Գործարկել ետնաշերտային ծառայությունը
Panak.exe --background

# Բացել Տեղադրման հրաշագործը (Installer Wizard)
Panak.exe --install

# Ավտոմատ լուռ տեղադրում
Panak.exe --install-silent

# Բացել Ապատեղադրման հրաշագործը (Uninstaller Wizard)
Panak.exe --uninstall
```

## Ծրագրի կառուցում (Build) եւ Կառուցվածք

### Նախապայմաններ
- **Windows 10 / 11** (x64)
- **.NET 8.0 SDK** (կամ ավելի նոր)
- Visual Studio 2022 (WPF գործիքներով) կամ VS Code

### Կառուցումը սկզբնաղբյուրից

```powershell
# 1. Պատճենել պահոցը
git clone https://github.com/hranthakobian/Panak.git
cd Panak

# 2. Կառուցել հիմնական նախագիծը
dotnet build

# 3. Գործարկել թեստերը
dotnet test

# 4. Հրատարակել Release տարբերակը
dotnet publish -c Release -r win-x64 --self-contained false -o publish Panak.csproj

# 5. Կառուցել ինքնաբավ Standalone Setup.exe տեղադրիչը
.\scripts\BuildSetup.bat

# 6. Կառուցել Microsoft Store MSIX փաթեթը (տես STORE_PUBLISHING.md)
.\scripts\BuildMsix.bat
```
